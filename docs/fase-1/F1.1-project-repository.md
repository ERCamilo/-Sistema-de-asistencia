## Decisiones de diseño

1. `reopen()`/`unarchive()` LIMPIAN `closedAt`/`archivedAt` — mantiene el invariante "requerido-si-status" de F0.3 sin dejar timestamps viejos.
2. `updatedAt` hereda `createdAt` al nacer: un recién creado nunca parece más fresco que sí mismo en merges LWW.
3. Id con padding por bucle (`Math.random().toString(36)` puede devolver <4 chars).
4. Factory rechaza nombre vacío; `endDate: null` explícito se preserva como null (ausencia ≠ null, según P5).
5. Sin código cloud/outbox todavía — publicación cloud es decisión diferida expresamente.
