📋 Información General

Control de Asistencia es una aplicación web progresiva (PWA) diseñada para gestionar la asistencia de empleados en proyectos de construcción. Esta política describe qué información recopilamos, cómo la usamos y cómo la protegemos.

📊 Datos que recopilamos

La aplicación puede recopilar los siguientes tipos de datos:

Datos proporcionados por el usuario:

  • Nombres de empleados, posiciones y líderes de equipo
  • Registros de asistencia (fechas, horas trabajadas, ausencias)
  • Configuraciones de nómina y adelantos salariales
  • Notas y observaciones sobre días laborales

Datos de autenticación (opcional):

  • Si el usuario inicia sesión con Google: nombre, correo electrónico y foto de perfil proporcionados por Google
  • El inicio de sesión es opcional y se usa únicamente para sincronizar datos entre dispositivos

Importante: La aplicación funciona completamente sin inicio de sesión. Los datos se almacenan localmente en el dispositivo del usuario por defecto.

💾 Almacenamiento de datos

Almacenamiento local (predeterminado):

  • Los datos se guardan en el navegador del usuario mediante IndexedDB y LocalStorage
  • Estos datos permanecen en el dispositivo y no se envían a ningún servidor sin el consentimiento del usuario

Almacenamiento en la nube (opcional):

  • Si el usuario inicia sesión y elige sincronizar, los datos se almacenan en Google Firebase (Firestore)
  • Los datos en Firebase están protegidos por reglas de seguridad que solo permiten acceso al propietario de la cuenta
  • Firebase cumple con los estándares de seguridad de Google Cloud Platform

🎯 Uso de los datos

Los datos recopilados se utilizan exclusivamente para:

  • Registrar y gestionar la asistencia de empleados
  • Generar reportes y estadísticas de asistencia
  • Calcular nómina y adelantos salariales
  • Sincronizar datos entre dispositivos del mismo usuario
  • Crear respaldos automáticos y manuales

No vendemos, compartimos ni transferimos datos personales a terceros. Los datos son exclusivamente del usuario que los creó.

🔐 Seguridad

  • La comunicación se realiza mediante HTTPS (conexión cifrada)
  • La autenticación se maneja mediante Firebase Authentication de Google
  • Los datos en Firestore están protegidos por reglas de seguridad que restringen el acceso exclusivamente al usuario autenticado
  • Los datos locales están protegidos por las políticas de seguridad del navegador (same-origin policy)

🌐 Servicios de terceros

La aplicación utiliza los siguientes servicios de terceros:

  • Google Firebase (Authentication y Firestore) — para autenticación opcional y almacenamiento en la nube. Política de privacidad de Firebase
  • Google Fonts — para tipografía (Inter). No recopila datos personales identificables. Política de Google Fonts
  • CDNs (jsDelivr, cdnjs) — para bibliotecas de código abierto (Chart.js, jsPDF, ExcelJS). Estos servicios pueden registrar direcciones IP en sus logs de servidor.

🗑️ Eliminación de datos

El usuario tiene control total sobre sus datos:

  • Datos locales: Pueden eliminarse borrando los datos del sitio desde la configuración del navegador, o usando la función de mantenimiento dentro de la aplicación
  • Datos en la nube: Pueden eliminarse usando la opción "Borrar datos de la nube" en la sección de Ajustes de la aplicación
  • Cuenta de Google: La aplicación no crea cuentas propias. El acceso mediante Google puede revocarse desde la configuración de permisos de Google

👶 Menores de edad

Esta aplicación está diseñada para uso profesional en la gestión de empleados y no está dirigida a menores de 13 años. No recopilamos intencionalmente información de menores de edad.
